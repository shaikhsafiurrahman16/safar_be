BASE URL: http://localhost:5000

AUTH ROUTES
Create user / Register: POST http://localhost:5000/auth/register
Login user: POST http://localhost:5000/auth/login
Logout user: POST http://localhost:5000/auth/logout
Refresh auth token: POST http://localhost:5000/auth/refresh-token
Read current profile: GET http://localhost:5000/auth/profile
Update current profile: PUT http://localhost:5000/auth/profile
Change password: PUT http://localhost:5000/auth/change-password
Request password reset: POST http://localhost:5000/auth/forgot-password
Reset password: POST http://localhost:5000/auth/reset-password
